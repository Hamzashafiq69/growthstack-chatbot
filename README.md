# GrowthStack AI Chatbot
A production-ready RAG chatbot that answers customer questions 
using a custom knowledge base. Built as a portfolio demo.

## Tech Stack
- Next.js 14 (App Router)
- Groq LLM (llama-3.3-70b)
- TypeScript
- Deployed on Vercel

## Features
- Real-time streaming chat UI
- RAG — answers grounded in knowledge base only
- Suggested questions sidebar
- Mobile responsive

## Run Locally

```bash
npm install
cp .env.local.example .env.local
# Add your GROQ_API_KEY to .env.local
npm run dev
```
